Browser Voice vs. Windows Wake Word

  • Website Voice Mode: Uses your browser microphone only after permission and sends the transcript to chat.
  • Windows Local Agent: Uses your custom offline Python wake-word engine (models/rizyee.onnx + Vosk) listening for "RIZYEE" → "Yes Shiva."
  • Browser Support: Chrome on Windows and Android supports Web Speech API over HTTPS; unsupported browsers fall back to text input.

Android & Remote Workflow

  1. Open this Netlify site on Android Chrome and sign in.
  2. Verify your Windows laptop shows Online.
  3. Type or speak a command like "Open VS Code".
  4. Approve sensitive actions before the Windows agent runs them.

Permission-Based Execution

RIZYEE never executes arbitrary AI-generated shell commands. Every request is classified into three levels:

  • A. Question: Answered directly in chat (e.g., "How do I create a folder?").
  • B. Plan: Proposed action + target path shown before running.
  • C. Approved Action: Validated against the action registry and executed safely.
